# CloneCoding

HTML, CSS, JavaScript를 활용한 웹 퍼블리싱 및 인터랙션 구현 연습 프로젝트 모음입니다.

## 프로젝트

| 프로젝트 | 구현 내용 | 사용 기술 | Live Site | 소스 코드 |
| --- | --- | --- | --- | --- |
| JOIN | 회원가입 화면의 입력 폼과 테이블 레이아웃을 퍼블리싱한 연습 프로젝트입니다. 실제 회원가입 서버나 데이터 제출 기능은 없습니다. | HTML, CSS | [사이트 열기](https://clonecoding-join.vercel.app/) | [join 폴더](https://github.com/ksejmr3/CloneCoding/tree/main/join) |
| KYUNGDONG | 기업 소개형 페이지의 섹션 레이아웃과 4개 메인 비주얼 슬라이드, 이전·다음 컨트롤을 구현했습니다. Swiper를 사용합니다. | HTML, CSS, JavaScript, Swiper 11 | [사이트 열기](https://clonecoding-kyungdong.vercel.app/) | [kyungdong 폴더](https://github.com/ksejmr3/CloneCoding/tree/main/kyungdong) |
| LOTTE WORLD | 민속박물관을 주제로 구성한 페이지로, 메인 이미지 슬라이드와 소개 배너, 전시 콘텐츠 카드를 구현했습니다. Swiper 12를 사용합니다. | HTML, CSS, JavaScript, Swiper 12 | [사이트 열기](https://clonecoding-lotteworld.vercel.app/) | [lotteworld 폴더](https://github.com/ksejmr3/CloneCoding/tree/main/lotteworld) |
| MUSIGN | 스튜디오 소개 페이지의 섹션 구성과 모바일 메뉴, 스크롤 기반 요소 표시 및 배경색 변화를 구현했습니다. | HTML, CSS, JavaScript | [사이트 열기](https://clonecoding-musign.vercel.app/) | [musign 폴더](https://github.com/ksejmr3/CloneCoding/tree/main/musign) |
